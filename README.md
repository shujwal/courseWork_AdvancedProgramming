Food waste and food insecurity are two major problems in society today. 
Every day, massive amounts of fresh, edible surplus food are thrown away by local restaurants, hotels, and grocery shops. 
At the same time, many vulnerable groups—including orphanages, old age homes, and rehabilitation centers—struggle constantly to secure proper daily meals. 
The Foodsharing Hub is an innovative web application designed to solve this critical issue by connecting surplus food sources directly with those in need.
Developed using Java web technologies and a structured Model-View-Controller (MVC) architecture, the platform creates a secure and transparent digital environment. 
It features dedicated dashboards for three primary user roles: Administrators, Donors, and Volunteers. 
Donors can seamlessly register and list their extra food, volunteers can view optimized collection tasks, and administrators retain full control over data logs and user records. 
Ultimately, this application turns community waste into a systematic, lifesaving food redistribution network.
